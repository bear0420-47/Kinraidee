## Search and rejection notes

Searched Wikimedia Commons API and file descriptions, web-indexed free-photo sources, and earlier Openverse search caches. Queries covered papaya/cucumber/rice-noodle salads, fried drumsticks, pork/cabbage dumplings, dry Thai suki, pork noodles, fried macaroni, grilled fish, sesame tofu, Adana/liver wraps and house-specific sauces. Commons briefly returned HTTP 429; a later exact-file metadata request succeeded. Paid-stock search results, restaurant/review images and pages with no explicit reuse grant were excluded.

Rejected: generic Adana wrap has no verified beef protein; wonton noodles include prawn dumplings absent from the red-pork noodle menu; an image named fried chicken drumstick actually shows boneless pieces; generic suki has unverified protein and cannot fill all pork/chicken/seafood variants; other papaya salads cannot stand in for cucumber or rice-noodle salad; spinach/sesame tofu is not plain sesame-fried tofu; grilled/fried fish without the required vegetable set does not match the set menu. No substitution was made merely because the search keywords matched.
